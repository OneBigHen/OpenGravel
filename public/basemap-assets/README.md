# Offline basemap assets

Glyphs and sprites for OpenGravel's own basemap (Lane A2), copied from
[protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets) so the
offline map never needs a third-party host.

- `fonts/`: Noto Sans Regular / Medium / Italic, Latin ranges only
  (0-255, 256-511, 8192-8447). SIL Open Font License, see `fonts/OFL.txt`.
  A label outside these ranges falls back to MapLibre's local glyphs.
- `sprites/`: Protomaps v4 `light`, derived from MIT-licensed tangrams/icons.
