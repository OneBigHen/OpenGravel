# Security

Please report suspected vulnerabilities through the **Report a vulnerability** action on the GitHub Security tab. Avoid posting credentials, private ride data, or an exploit that affects other users in a public issue.

Include the affected version or commit, the conditions needed to reproduce the issue, and its practical impact. We will acknowledge reports as soon as we can and coordinate a fix before public disclosure when a report is confirmed.

Do not put real credentials in `.env.example`, tests, screenshots, or issue attachments. Use `.env.local` for local secrets; it is ignored by Git.
